# Заготовки контента слайдов, затронутых новыми данными (04, 06, 09, 12–14)

Черновик для Figma (задачи 01, 03, 06, 08). Формат — как в `docs/slides_01-03.md`:
заголовок → числа с источниками → рисунок с подписью → тезис → оговорки.
Каждое число из файлов репозитория пересчитывает `scripts/check_numbers.py` (99/99),
веб-числа внесены в `docs/numbers_check.md`. Карты пока НЕ отрисованы — указано, что
нужно построить в `scripts/maptools.py` (единый макет, подложка relief, без заголовков).

## Слайд 04. Расселение и демография (задача 01, Арина К.)

**Заголовок:** Население: половина — в агломерации, периферия держится, но точечная.

**Числа и тезисы:**
- 210 095 жителей (1.01.2025); 45,1 % — в агломерации Горно-Алтайск — Майма на 1,5 %
  площади. *`mo_summary.csv`.*
- Прогноз агломерации к 2035 г. — **вилка 89–123 тыс.**: в концепцию берём трендовый
  (89–92 тыс.), официальный (122,6 тыс. по документам МО) — верхняя граница для резервов.
  Основание: Горно-Алтайск −0,86 %/год, агломерация −0,41 %/год (2023–2025).
  *`docs/decisions_2026-11-03.md`, реш. 2.*
- Опорная сеть: **37 ОНП**, в них 74,9 % населения; критерии: центр МО, больница или
  амбулатория, ≥1 500 жителей. Сверка с реестром Минздрава: у **36 из 37** есть
  действующая точка медпомощи в своём НП (20 больница/центр, 15 амбулатория, 1 ФАП);
  исключение — Элекмонар (кандидат по населению). *`data/onp_candidates.csv`,
  `scripts/access/medical_registries.ipynb`, `docs/decisions_2026-11-03.md`, реш. 4.*
- Образование: на портале Минобрнауки **179 организаций с сайтами** — 131 школа,
  32 сада, 16 ДОД; школы есть в каждом районе, сады сконцентрированы в агломерации
  (13 из 32 — Майминский + Горно-Алтайск). *`data/education/obr04_summary.csv`.*

**Рисунок (построить):** карта расселения — НП по населению + 37 ОНП + ядра/межрайонные
центры (слои `data/onp_candidates.csv`, `data/dataset_v3/geo/`).

**Подпись к рисунку:** Рис. 4. Расселение и опорная сеть (37 ОНП; межрайонные центры
решением от 03.11.2026 — Кош-Агач и Усть-Кан). Источники: БД ПМО/перепись-2020
(`data/dataset_v3/`), реестр МО Минздрава РА (2026), решение команды от 03.11.2026.

**Тезис для доклада.** Сеть услуг уже точечная и агломерационная: концепция не «размазывает»
рост, а закрепляет 37 опорных НП и два межрайонных центра — под трендовое население,
с резервом под документный сценарий.

**Оговорка:** реестр МО — не слой точек (без координат; «действует» по полю «исключено»);
сады на портале — только имеющие сайты, полный счётчик садов не из этого источника.
