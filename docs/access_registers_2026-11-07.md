Пересчет выполнен для 247 населенных пунктов, 210 094 жителей в расчетном слое. Результаты по [муниципалитетам](../data/access_results/register_services_by_mo.csv) и [населенным пунктам](../data/access_results/register_services_by_settlement.csv). Точки и основания их отбора — в [реестре геокодирования](../data/access_inputs/service_registers_geocoded.csv).

Для школ сверены поля основного адреса и адреса филиала на сайтах организаций. Из 167 строк в 146 совпал опубликованный адрес, в трех подтвердилось расположение в населенном пункте или на улице. В четырех строках подтверждена организация по региональному каталогу, а 14 строк относятся к недоступным страницам. Совпадение с сайтом подтверждает опубликованный адрес. Наличие действующей лицензии по этому адресу — отдельное поле федерального реестра. Школьная выборка исключает вечерние школы, поскольку они не заменяют общеобразовательную школу для обычного подвоза. Записи с одним зданием схлопываются при формировании маршрутов. Координаты для 113 школьных и 32 непроектных медицинских записей взяты из OSM по адресу здания или объекту. Остальным 54 школьным и 133 непроектным медицинским записям соответствует точка населенного пункта. Из строк СТП 14 сопоставлены по адресу, 36 по населенному пункту и четыре остались без координат. Привязка к центру села задает приближенное положение, особенно для протяженных сел. В CSV уровень точности хранится отдельно от источника и статуса.

Доли описывают конкретные наборы точек. В адресной выборке учитываются 100 школьных точек и 36 медицинских, включая больницы из базового слоя. Оценка по ней показывает охват этой части сети. В расширенном варианте часть пути исчезает, когда центр поселения одновременно служит точкой спроса и приближенной координатой услуги. Для решения по школьному подвозу используем адресный набор и прежнюю карту OSM как две проверки, а приближение по центрам сел оставляем в анализе чувствительности. Расчет не оценивает пешие маршруты, вместимость школ и расписание приема.

Граф строится по выгрузке OSM на 07.11.2026 00:00 UTC (MD5 `50999f30b163ddec7ea1feaf9e2da926`). В нем 30 703 узла и 37 754 ребра, веса времени учитывают рельеф Copernicus DEM по методу проекта. ## Воспроизведение

Шаг `extract` использует PyOsmium, `--school-pages` — Beautiful Soup. Папка страниц содержит ответы официальных сайтов в HTML, имя файла — первые 16 шестнадцатеричных символов SHA‑256 от исходного URL плюс `.html`. В таблицу перенесены только служебные поля проверки и институциональные адреса. На этапе геокодирования без `--school-pages` фиксируется совпадение родительской организации с региональным каталогом.

```bash
python scripts/access/build_graph_from_pbf.py extract altai_republic.pbf roads.jsonl
python scripts/access/build_graph_from_pbf.py build roads.jsonl results/service-registers-2026-11-07
python scripts/access/geocode_service_registers.py /путь/к/книгам altai_republic.pbf register.csv --school-pages /путь/к/страницам
python scripts/access/recalculate_service_registers.py results/service-registers-2026-11-07/offline_mountain.urbangraph register.csv data/access_results
```
