# Организации образования РА — каталог портала obr04.ru (03.11.2026)

## Источник

Портал образовательных организаций Республики Алтай (Минобрнауки РА):
<https://obr04.ru/organization/>. Обход всех страниц каталога и фильтров
«Школа / Детский сад / ДОД» сделан через браузерную автоматизацию
(`scripts/dataset/education_portal.ipynb`).

## Что внутри

| Файл | Содержимое |
|---|---|
| `obr04_organizations.csv` | 179 организаций: название, тип, район, НП, сайт, координаты НП |
| `obr04_summary.csv` | сводка по районам и типам |
| `obr04_raw.json` | сырой обход каталога без фильтра (131 школа) |
| `obr04_by_type.json` | сырые списки по фильтрам (131/32/16) |

Состав: **131 школа, 32 детских сада, 16 организаций ДОД**.

Район определён у 150 из 179 сопоставлением названия организации с населёнными пунктами
из `data/dataset_v3/settlements.csv` (прямое вхождение, прилагательные «Талдинская» ← Талда,
«республиканские» → Горно-Алтайск). 29 строк — «не определён» (частные сады без топонима,
республиканские организации без адреса в названии).

## Оговорки

- Портал перечисляет организации, имеющие **сайты на нём** — это не полный реестр
  образовательных организаций региона (полные счётчики — в ФРМО Минздрава для
  образования и статистике Минобрнауки). По школам покрытие близко к полному
  (131 ≈ число дневных школ РА), по садам и ДОД — заведомо неполное.
- Пагинация портала зацикливается: страницы после 14-й повторяют первую.
- Дата обхода: 03.11.2026.
