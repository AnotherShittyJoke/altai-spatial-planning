# ОКН из ЕГРОКН — вырезка по Республике Алтай (03.11.2026)

## Источник

Выгрузка ЕГРОКН `data-70-structure-16.csv` (516 МБ, вся Россия, 163 701 запись; получена
Денисом 28.10.2026). Вырезка сделана блокнотом `scripts/okn/egrokn_altai_cut.ipynb`:
фильтр по `Id-Регион = 04`.

## Что внутри

| Файл | Содержимое |
|---|---|
| `egrokn_altai.csv` | 288 объектов: название, категория, район, адрес, рег. номер, документ о постановке на охрану, координаты (где есть) |
| `egrokn_altai_points.geojson` | 76 точек с координатами (поле «На карте» выгрузки, GeoJSON Point, EPSG:4326) |
| `okn_by_mo_egrokn.csv` | сводка по районам: федеральные / региональные / местные |

Состав: **117 федеральных + 170 региональных + 1 муниципальный = 288**.
Выявленные объекты (318 по приказам и 2 130 по перечню 2018) в ЕГРОКН не входят —
см. `data/stp_extracted/okn/`.

## Сверка с СТП (Том 3)

| Категория | СТП | ЕГРОКН | Комментарий |
|---|---|---|---|
| Федеральные | 118 | 117 | 2 объекта ЕГРОКН не связались по рег. номеру с реестром СТП (Кызыл-Телань-1, «Группа курганов»), 1 федеральный СТП в ЕГРОКН не найден |
| Региональные | 170 | 170 | совпадает |
| Местные | 0 | 1 | «Территория бывшего села Кумжулу (Камышла)», Шебалинский район — новый объект |

Район у 115 федеральных восстановлен по реестру СТП (совпадение по регистрационному
номеру), у остальных — по адресу; у 3 объектов район не определён.

## Оговорки

- **Координаты есть только у 76 из 288** — поле «На карте» выгрузки заполнено не для всех.
  Остальные можно догеокодировать по адресам/ФИАС или взять из OSM (historic=*).
- Колонка «Тип ОКН» в выгрузке пустая; вид объекта — в `stp_extracted/okn/`.
- Доли ЮНЕСКО все «нет» — объект ЮНЕСКО «Золотые горы Алтая» покрывает территории
  заповедников, а не отдельные ОКН.
